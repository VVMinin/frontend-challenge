# Кошачий Pinterest
Тестовое задание: интерфейс для просмотра изображений котиков с использованием [The Cat API](https://thecatapi.com/).
## Стек
- React + Vite
- TypeScript
- Axios
- Redux Toolkit
- Ant Design
## Архитектура
Проект организован по FSD-слоям:
- `app`
- `pages`
- `widgets`
- `features`
- `entities`
- `shared`
## Реализовано
- Вкладка **«Все котики»** открывается по умолчанию.
- Загрузка котиков с API (`/images/search`) через Axios.
- Бесконечная прокрутка (infinite scroll) с догрузкой данных.
- Возможность добавить/удалить котика в избранное.
- Вкладка **«Любимые котики»** с отображением сохранённых котиков.
- Хранение избранного в `localStorage`.
- Модальное окно просмотра котика:
  - открытие по клику на карточку,
  - навигация между котиками стрелками.
- Обработка состояний загрузки и ошибок.
- Адаптивная сетка карточек.
